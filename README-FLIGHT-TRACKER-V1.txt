AVIQUEST LIVE FLIGHT TRACKER V1

New in this build:
- Full-screen live aircraft map
- Current-location tracking
- Search by callsign, registration, ICAO hex or aircraft type
- Selectable aircraft map markers and aircraft list
- Aircraft photo lookup using the existing Netlify photo function
- Details panel with distance, altitude, speed, heading and last-seen time
- A7-BAF quick-search buttons
- Tracking radius from 46 km to 463 km
- Direct button from the tracker into Live AR
- Automatic live refresh every 30 seconds
- New Flight Tracker button on the AviQuest home page

Important limitation:
The existing free ADS-B data source supplies live positions but usually does not provide full origin, destination, gate, terminal or official flight-plan data. Those fields can be added in the next stage using a schedules/flight-status API.
