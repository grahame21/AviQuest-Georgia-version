AVIQUEST CLEAN TRACKER + SPOTTED v3

CHANGES
- Removed the large row of My location / Favourites / Saved buttons.
- These controls now sit as compact icons inside the search bar.
- Removed the large bottom navigation from the tracker.
- Reduced the header, tabs, map status, aircraft count, nearby button and aircraft markers.
- Aircraft details remain completely hidden until an aircraft is deliberately selected.
- Added a small A7-BAF shortcut instead of a permanent full navigation item.

SPOTTED AIRCRAFT
- AR Spotted: automatically lists aircraft marked from Live AR Spotter with date, time and live data.
- Camera Spotted: lets Georgia take/select a photo and save a date, time, registration, airline, aircraft, location, livery and notes.
- Camera input requests the rear camera on supported phones.
- AR and Camera records remain separate categories.

INSTALL
Upload every file inside AviQuest-Georgia-version-main to the root of the GitHub repository, replacing the current files.
Wait for Netlify to finish deploying, then fully refresh Safari.
